镜头号规则与制作约定

  • 编号规则：SC - 幕号 - 镜号，如 SC-03-04 为第三幕第 4 镜；镜头号在成片剪辑与配音表之间保持一致，便于对轨。

二、建议的录制脚本（按此顺序一遍录完）

  1. 打开页面，先停在主视觉 3 秒，让标题与「作品形态：可交互网页动画原型」入画。
  2. 点「播放短片」，完整播放四幕；期间不再操作，保留一次连续的叙事节奏。
  3. 播放结束后点「从头开始」，回到第一幕，切换到右侧排版台。
  4. 现场排一句：点选或拖入 7 枚左右字模，用方向键调整一次顺序，点「校验这一句」，再点「校正」。
  5. 点「推墨试印」，展示印版反字与纸面正字的双栏对照，切换一次「竖排 / 横排」。
  6. 点「导出 PNG」，打开作品说明抽屉并滚动展示各分区，最后停在分镜脚本表。

史料对照卡：记载与本页舞台化表达的区别

本卡片为依据公开介绍整理的要点概述，未引用《梦溪笔谈》原文，也不构成印刷史学术结论。需要准确文字与断代的，请核对原著或权威整理本并请专业教师复核。

A · 沈括《梦溪笔谈》关于毕昇活字的常见公开要点

  • 记载对象为毕昇所创的活字印刷方法，时代通常归于北宋；各类介绍多将其列为有明确文献记载的早期活字实践。
  • 用材为胶泥（泥活字）：刻字后经火烧加固，一枚一字。
  • 排版环节提到以铁范（铁板）承字，并以黏性辅料（常见说法为松脂、蜡与纸灰之类）铺填固定。
  • 强调可重复组合、多次使用：同一批字印可反复排成不同内容。
  • 性质为古代笔记体的见闻记录，与现代工艺图纸或技术专利文本不同，细节留有解释空间。

B · 本页为了舞台效果做了哪些改动

  • 材质不同：页面出现的是木质字块与木盘，而上述记载所说为胶泥（泥活字）。木色调仅为便于视觉辨识的美术选择。
  • 场景不同：油灯、案面、连续劳动的一夜等，均为艺术化舞台调度，不以某处作坊为复原对象。
  • 人物与台词虚构：学徒角色、旁白与所有对话为原创虚构，不代表任何真实历史人物的言行。
  • 流程压缩：拣字、上墨、覆纸、刷印、揭纸的顺序被压缩成四幕，工序细节经过简化。
  • 结论边界：本页不主张任何关于印刷史起源、断代或工艺还原度的学术结论。

1 · 作品简介与目标观众

作品名称：活字的一夜：字模学徒的印刷工坊

参赛赛项：自主选题类 · 影视与动漫创作类 · 二维动画与新媒体漫画

当前形态：可交互网页动画原型（单文件 HTML，CSS/JS 绘制，无外部依赖）

简介：作品以一位虚构的手工字模学徒为主视角（时间背景作艺术化处理，不指向具体朝代与地点），用四幕短剧讲一夜之间拣字、排版、试印到成篇的过程。页面把叙事与操作接在一起：观众排出的那一行字，会真正进入印版和纸面。

目标观众：中小学与非遗科普场景的读者；高校通识课与数字媒体专业课堂；印刷文化爱好者。也作为团队内部的教学示范原型。

预计体验时长：交互浏览约 3 至 5 分钟（不含后续成片）。

2 · 创新点

  • 一、可参与的活字排版叙事。观众不是单纯看片：通过点选、拖拽、删除排出一句话，这行字直接驱动舞台上的字盘道具、尾声的画面文案与输出结果，叙事状态与操作状态共用同一数据源，形成「操作—校验—再叙事」的闭环。
  • 二、印版反字与纸面正字对照。大量科普动画只呈现纸上的成品；本作同时给出印版（镜像反字）与纸面（正字）双栏对照，把「为什么活字要刻成反字」这一关键认知点可视化，并支持导出 PNG 与 SVG，让成果可带出展播现场。
  • 三、史料与舞台化表达分离。页面设置独立的史料对照卡，一列写明《梦溪笔谈》相关记载的公开要点概述，另一列逐条列出本页为舞台效果所做的改动（木质而非记载中的胶泥、虚构角色与对话、意象化的灯光与纸光），叙事归叙事，史料归史料。
  • 与常见非遗科普动画的差异：常见做法是线性 MG 图表加配音解说，观众一次性看完、无法操作；本作提供可操作、可校验、可导出的闭环，并把「清楚标注边界」本身作为设计要求的一部分。

3 · 技术路线

  • 结构：单个 HTML 文件，零构建、零第三方依赖；可直接双击打开或托管到任意静态服务器。
  • 动画：全部使用 CSS @keyframes 与 transition，JavaScript 只负责任务调度与状态同步；未使用任何外部动画/绘图库（无 GSAP、Three.js、Lottie 等）。
  • 绘制：字模、木盘、油灯、案面为 CSS 图形（渐变、盒阴影、圆角）绘制；纸面成品由 Canvas 2D 实时绘制，包含纸色渐变、纤维噪点、双线边框与朱印。
  • 导出：PNG 使用 canvas.toBlob 配合 Blob URL 触发下载；SVG 由脚本按坐标拼接字符串生成，提供文件下载与源码复制两种方式。
  • 状态管理：以一个 JavaScript 数组作为「这一行字」的唯一数据源，字盘、句子顺序、校验结果、印版、画布与导出文件名均由它派生，避免界面之间状态不一致。
  • 无障碍与降级：尊重 prefers-reduced-motion，减少动效时改为静态分段整幕呈现；全流程键盘可达，焦点样式统一使用 :focus-visible。

4 · 操作与运行说明

  • 运行：双击本 HTML 即可运行，或在文件目录执行 python -m http.server 后浏览器访问；除史料链接外不需要联网。
  • 环境：建议使用支持 Canvas 与 Blob 的现代浏览器（Chrome / Edge / Firefox / Safari 近年版本）；建议分辨率 1280×720 起，窄屏自动切为单列。
  • 剧本操作：播放/暂停、上一段、下一段、第一至第四幕直接跳转、从头开始；右上角幕次按钮可跳幕。
  • 排版操作：点选或拖入字模 → 句子顺序可拖拽调整 → 点「校验这一句」查看提示 → 需要时点「校正」 → 点「推墨试印」更新双栏对照 → 导出 PNG / SVG。
  • 已知限制：导出依赖浏览器的 Canvas 与 Blob 支持；竖排/横排切换会同时影响纸面成品与导出文件；未做服务端保存，刷新后句子回到默认。

8 · 艺术风格说明（视觉设定）

  • 配色与留白：整体取仿古籍纸色体系——纸面 #f4ead6 系渐变、墨色 #2a241e、朱色 #a94334、夜景 #1f2b2c。纸面画布上下各留 130px 余白、左右各留 62px，正文四周保留双线边框，以「疏可走马」的留白压住信息密度。
  • 字模造型：长方形木块，比例约 42×52（宽:高≈0.8:1），圆角 4px；顶面加内描边高光、底部加 3px 实心投影模拟厚度，侧面用木色渐变。造型为便于辨识的舞台化示意，未做实物测绘，此点已在史料对照卡中声明。
  • 纸纹与朱印：纸纹由 Canvas 绘制 1500 个随机纤维点（尺寸约 1.6×1.1px，透明度 0.012–0.062），叠在冷暖渐变的纸色底上；朱印为右下角 62×62 朱红方块加一个「印」字，模拟钤印位置，非任何具体印鉴的摹写。
  • 竖排 / 横排的取舍：默认竖排（贴近古籍阅读习惯，字序自上而下、列序自右向左，每列最多 11 字）；横排作为现代阅读习惯与低龄观众的备选。两套版式共用同一份「已排字序」数据，只是坐标算法不同，因此切换不会造成内容不一致。
  • 动效节奏：全部为 CSS @keyframes / transition，JavaScript 只做调度。单句停留时长按字数估算（900ms + 95ms×字数，夹在 1.8–5.2 秒之间），段间留呼吸；镜头动作（推、摇、擦印）用 0.7–1.6 秒的短动画示意，不做写实模拟。
  • 减少动效降级方案：系统开启 prefers-reduced-motion 时，取消全部动画与过渡，改为整幕五句一次性静态列出，并停用自动播放按钮，改为「上一段 / 下一段 / 跳幕」逐句阅读。所有叙事信息在降级路径下不丢失。
  • 素材来源：字模、木盘、油灯、案面、纸面、朱印全部由 HTML / CSS / Canvas 代码绘制，无第三方图片、字体、图标或音频素材；文字仅使用系统字体栈（Songti SC / SimSun / Noto Serif SC / 微软雅黑 等），未内嵌或引用任何外部字体文件。

9 · 传播与教学使用建议

  • 适用场景：① 非遗与传统文化教育（活字印刷主题的通识课、社团活动）；② 校园文化活动（读书节、科技人文节展台，可现场排字并导出带走）；③ 中小学研学与课后服务（配合手工活字体验课使用）。
  • 建议流程（约 15 至 20 分钟）：观看 3 分钟 → 亲手排一句 → 讨论 → 导出自己的那一页。
  • 第一步 观看（约 3 分钟）：完整播放四幕，或由教师按幕分段讲解「拣字—整理—试印—成篇」四个环节。
  • 第二步 亲手排一句（约 5 分钟）：每人排出一句 5 至 12 字的话，用方向键调整顺序，点「校验这一句」看提示，再点「推墨试印」，观察印版反字与纸面正字的差别。
  • 第三步 讨论（约 8 分钟）：围绕下面两个问题分组交流，每组派代表复述一句本组排出的句子。
  • 第四步 带走成果（约 2 分钟）：导出 PNG 或 SVG，打印或贴在班级展示栏；导出图角落带「原型演示 · 非史料复刻」说明行，避免被误当作史料图像使用。
  • 讨论问题 1：活字为什么是一种「拆分重组」的思维？把一句话拆成单字、再重排成别的话——这种先拆后组的做法，在你写作文、整理笔记或写程序的时候能怎么用？
  • 讨论问题 2：试印偏斜时，学徒选择重排一次而不是将就。如果让你在「赶快交出去」和「重做一遍」之间选，你会怎么判断？留在纸上的痕迹，和留在屏幕上的痕迹有什么不同？
  • 使用提示：本页含虚构角色与台词，用于讨论「技术如何改变知识的复制与传播」是合适的；若涉及具体断代、材质与工艺结论，请回到史料对照卡并核对权威资料。
